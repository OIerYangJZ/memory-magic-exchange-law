## 第 1 轮（2026-10-02）：范数平均体积律的精确形式

**子目标。** 把 §9 的"按范数平均的管体体积律"写成带显式误差项的陈述，并回答 (i)(ii)(iii)。

**设定。** X_m = {w ∈ O : nrd w = m}，m ∈ O_K⁺ 模全正单位 (3+2√2)^Z。|X_m| = r_O(m) = 48 Σ_{d|m} N(d)（m 与 P 互素时精确；一般 ≍ N(m)^{1+o(1)}）。
管体计数 N_m(f) := Σ_{w∈X_m} f(σ₁(w)/√σ₁(m))，f 是 SO(3) 上光滑化的 ε-管体指示函数（Sobolev 范数 ≲ ε^{-C}），σ₂ 自由。

**中间结论 1（平均陈述，严格，路线 = Marshall Prop. 5.2 + Jacquet–Langlands）。**
设 g 是 (R⁺)² 上支在 [1/2,2]² 的光滑函数，M₁M₂ = M。则
  Σ_m g(σ₁m/M₁, σ₂m/M₂) N_m(f) = (∫f)·Σ_m g(…) r_O(m) + O_A(ε^{-C} M^{-A})，   只要 M ≥ ε^{-2-δ}。
证明骨架：N_m(f) = Σ_ψ ⟨f,ψ⟩ψ(x₀)λ_ψ(m)，ψ 跑遍 O 上权 (a,0)、a ≲ 1/ε 的 Hecke 特征形；非平凡 ψ 经 JL 对应 K 上的尖点 Hilbert 形式，L(s, π_ψ ⊗ λ_ν) 整（λ_ν 是 K 的无分歧 Grössencharacter，用来探测 (σ₁m, σ₂m) 盒子），把 Perron 围道推到 Re s = −A，函数方程给出 (解析导子)^{A+1/2} M^{-A}，导子 ≍ a²(1+|ν|)² ≲ ε^{-2}。
在汇率相关范围 τ ∈ [2L, 3L] 内 M = 2^τ ≥ ε^{-2-δ} 成立（除 τ = 2L 端点）。

**(i) P^τ 在平均中的权重。** 盒内范数个数 ≍ M/(√8·log(3+2√2)) ≍ 2^τ，所以权重 ≍ 2^{-τ}。

**(ii) 从平均到单范数差什么。** 整个平均。没有部分结构可借：
- 子族 {P^τ l : (l,P)=1, N(l) ≍ Λ}：因 λ_ψ(P^τ l) = λ_ψ(P^τ)λ_ψ(l)，对 l 求和后误差为 Σ_ψ |⟨f,ψ⟩ψ(x₀)|·|λ_ψ(P^τ)|·Λ^{-A}，Λ ≥ ε^{-2-δ} 时可忽略。但 X_{P^τ l} = X_{P^τ}·X_l/48（互素范数的唯一分解），于是该陈述等价于 Σ_{v∈X_l} N_{P^τ}(cap·v) = 体积 —— 这是帽子的 Hecke 轨道平均 = 全体帽子平均，即 Hecke 点在尺度 ε 的等分布。正是 agent_linnik §3(d) 的"放大恰好中性"。无新信息。
- 范数窗口邻居（|σ₁m − 2^{τ/2}| ≤ w²，约 ε^{-1/2} 个）：它们与 P^τ 的唯一区别是 P-进深度；行列式法对窗口并集已经紧（agent_decoupling §1）。

**(iii) 正性。** N_{P^τ}(f) ≤ Σ_m g N_m(f) ≈ 2^τ·(2^τ ε²)，损失整整 2^τ。按范数的二阶矩给 (2^τ·vol)^{1/2} = 2^τ ε，比 Ramanujan 的 2^{τ/2} 还差。2k 阶矩给 2^{τ/2k}·vol^{1/2}，k→∞ 才到 vol。都没用。

**本轮结论。** 平均陈述是常规的、严格的，但对单范数一无所得；"α = 3 ⟺ P^τ 在平均中不例外"这句话在数学上没有可操作的内容。子目标关闭，结果为负。

## 第 2 轮（2026-10-02）：检验"6 点关联循环"论断；关联的树距离分解

**子目标。** §13(a) 说算术中心的 5 阶矩 Σ_ψ N(cap_ψ)^5 与 6 点关联互相改写、循环。检验这是否真的循环，顺便把最低阶的开放关联（3 点）写成最具体的算术形式。

**记号。** V 跑遍 Clifford 管体 T_ε(T_z) ∩ Λ_{2τ}（sde τ，T-count 2τ）；总数 T = Σ_P n(P) ≈ ε²4^τ（Theorem A，除数界，已证）。n(P) := #{V ∈ 管体 : V 的前 τ 个音节 = P}，P ∈ Λ_τ。vol := ε²2^τ = n(P) 的均值。临界尺度 ε = 2^{-2τ/5}，vol = 2^{τ/5}，cells = 2^{2τ/5}。

**中间结论 2.1（k 阶矩 ⇒ 汇率 3 − 2/k，k 可为奇数）。** max_c N_c ≤ (Σ_c N_c^k)^{1/k} 不需要 k 为偶数。所以：2 点 ⇒ 2；3 点 ⇒ 7/3；4 点 ⇒ 5/2；**5 点 ⇒ 13/5 > 5/2**；6 点 ⇒ 8/3。HANDOFF 只列了 6 点 ⇒ 8/3；5 点关联上界已经足以突破 5/2。4 点关联上界本身也**未被证明**（行列式法给的是 sup 界，不是矩界：sup·L² 插值差一个 ε^{-1}/vol = ε^{-1/2}）。

**中间结论 2.2（三点关联的四种等价写法，全部严格）。**
  Σ_P n(P)² 
  = #{(V,V') ∈ 管体² : 共享长度 ≥ τ 的前缀}
  = #{(u,t),(u',t') ∈ 管体² : ut' ≡ tu' (mod √2^τ) in Z[ζ₈]}       （P-进斜率同类）
  = #{(A, B) ∈ Λ_τ², D := A⁻¹B ∈ T_{2ε}(T_z)} 之上 #{P ∈ Λ_τ : PA, PB ∈ 管体} 之和
  = Σ_{j} ⟨A'_{2j} 1_管体, 1_管体⟩，A'_{2j} = 壳层内树距离 2j 的邻接算子。
由 L1 分离（agent_linnik），树距离 2j 的管体点对在 j < 2log₂(1/ε) − O(1) = 4τ/5 时**不存在**；只有 j ∈ [4τ/5, τ] 贡献，第 j 项 = Σ_{深度 j 的 ε-近对 (A,A')} #{P ∈ Λ_{2τ−j} : PA, PA' ∈ 管体}。j = τ 项就是 Σ_A N_τ(cap_A)² 本身，j = 4τ/5 项的内层是深度 6τ/5、围绕深度 4τ/5 算术点的帽子计数（高度 h 的算术框架，Theorem A 损失 2^h，没用）。
**结论：循环论断成立。** 所有改写都回到"围绕深度 τ 算术点、深度 τ 的帽子计数"。无新结构可用。

**中间结论 2.3（Bloch 向量形式：Archimedean × P-进联合帽子）。** 以 ν = Bloch(u,t) ∈ Z[√2]³，|ν|² = 4^τ（两个嵌入）。前缀类 P ⟺ ν ∧ ν_P ≡ 0 (mod √2^τ)，ν_P 是深度 τ 点的 Bloch 向量。P-进上 |ν|² = 4^τ → 0，所以 [ν] 靠近各向同性锥 C₀: x²+y²+z² = 0 ⊂ P²(K_P)，C₀(K_P) ≅ P¹(K_P) = 3-正则树的边界，前缀类 = 边界上深度 τ 的球。于是两轮问题 = **K 上球面 x²+y²+z² = 4^τ 的整点在 (σ₁ 处 ε-帽) × (边界上深度 τ 的 P-进球) 中的联合分布**。这是"联合等分布 / joining"类型的问题（Aka–Einsiedler–Shapira 风格），但那里的结果定性、且需要两个素数；这里只有一个素数、要收缩尺度的有效速率。谱形式回到 §12(b)/§14(a) 的三重积和 Σ λ_fλ_gλ_h⟨fgh⟩。

**中间结论 2.4（算子范数形式）。** 令 M(P,A) = 1[PA ∈ 管体]，2^τ × 2^τ 的 0/1 矩阵，T 个 1，每个管体元 V 恰给一个 1（中点切分）。三点关联 = ‖M·1‖²；‖M‖_op ≤ 2^o·vol 蕴含对所有权重的三点界。‖M‖⁴ ≤ #(二部图 4-圈) = 管体的乘法能量子项；Peter–Weyl 把 M 拆成 ≈ ε^{-3} 个秩一片，三角不等式给 ‖M‖ ≤ vol·ε^{-3/2}，没用，需要片之间的相消 = 问题本身。

**本轮结论。** (a) 循环论断正确。(b) 小修正：5 点关联即可 ⇒ 13/5；4 点关联本身也是开放的。(c) 得到一个干净的联合帽子表述（2.3），但没有新的证明机制。
